## 四、已知限制（如实说明）

1. **macOS / Android / iOS 安装包未实际产出**：本机为 Windows，无 Xcode、Android SDK、macOS 签名环境。已交付完整可执行配置与 6-job GitHub Actions 流水线，在有对应工具链的机器/CI 上一键产出。
2. **PDF 导出**：服务端无 headless 浏览器，按契约返回带 print CSS 的 HTML 由前端 `window.print()` 打印为 PDF。
3. **支付通道未接入真实商户**：订单一律创建为「待支付」，管理员可手动确认到账；退款/卡密/订单体系完整可用。
4. **SMTP / 短信验证码**：配置项与接口齐备，未接入真实服务商，注册/绑定仅做格式校验。
5. **搜索为遍历式**：逐篇读 OSS 取正文，文档 >2000 篇会变慢（已跳过 >3MB 文件、上限 200 命中）。建议后续加全文索引表。
6. **限流为单机内存 + DB 固定窗口**，多实例部署需换 Redis。
7. **分屏拖动调宽**未实现（已可切换左右/上下分屏）。
